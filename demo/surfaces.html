Views are keyed by window id, so a layout change moves each view element instead of recreating it. The renderer places containers first and moves views with moveBefore(), so iframes don't reload, CSS animations and scroll positions carry on, and inputs keep their values.
Hiding a view (minimize, fullscreen elsewhere, another workspace) unmounts its surface. htmlSurface keeps its element and re-attaches it (an iframe inside still reloads). lazySurface rebuilds from scratch.
