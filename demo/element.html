Works entirely offline: no framework, no build step. <wa-stage> is a plain HTMLElement subclass that owns its own window manager, DOM renderer and input adapter for as long as it is connected, and exposes what it made: .wm, .renderer, and for the palette and sync options .palette (the button calls stage.palette.open()) and .sync (the tab count reads stage.sync.peers(); open this page in a second tab).
